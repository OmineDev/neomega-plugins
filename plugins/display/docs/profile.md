# 实验性普通物品 profile

`fmbe:ordinary-item-yaw-v1` 将结构化物品、世界坐标、统一缩放与 Y 轴静态/旋转参数转为狐狸持物及五层动画。精确支持集和限制以 `describe().payload` 为准。

该实现独立编写，仅约简普通物品的 yaw 变换；算法和校准数据来源记录在 [`profile.py`](../plugin/display_provider/profile.py) 的 provenance 中，指向 [szea-ll14 的 FMBE 说明](https://github.com/szea-ll14/mcbe-cmd-memo/discussions/5)。本项目不分发其地图、模型、材质或原始长表达式；原素材的再分发许可尚未确认，本项目 MIT License 不授予这些素材的权利。

| 可确认的合同 | 使用限制 |
| --- | --- |
| 世界可见 | 没有逐观察者过滤；owner 是管理归属，不是私有显示。 |
| 世界锚点以方块为单位 | 表示载体位置；物品中心与模型偏移需要目标客户端校准。 |
| 静态与 Y 轴旋转 | 旋转由客户端实体时间求值，更新可能跳相位。 |
| 精确载体标识 | 清理受加载范围和世界 session 约束；待清理不代表已删除。 |
| 有限参数和物品集合 | 不接收任意选择器、Molang 或命令。 |

普通狐狸的 AI、重力、碰撞、受伤和可能的名称显示仍存在。减速或传送不能自动证明载体静止。客户端资源要求、动画叠加顺序、刷新持久性、三轴视觉校准与帧率保持未验证，除非另有目标环境的对应证据。

展示物品可能因狐狸死亡或换物行为进入可拾取世界物品，当前不保证经济隔离。正常清理会先清空持物再删除载体，但无法消除清理前发生的掉落；实验应使用与正式物品经济隔离的场地。

`describe` 的实验性标记不会因为离线测试、打包检查或命令回执自动升级。服务器动作结果、实体读回和玩家画面分别记录；没有客户端画面时，`client_visible` 不作为已验证事实。
