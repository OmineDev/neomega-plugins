# 口令红包

玩家在聊天栏用金币发拼手气红包或口令红包，全服玩家发送 `!抢` 领取随机金额；红包被抢完时全服播报「手气最佳」，过期未领完的剩余金币自动退回发包人。管理员还可以发不扣个人金币的系统红包。安装时需要搭配「经济」插件使用。

## 玩家命令

| 命令 | 作用 |
| --- | --- |
| `!发红包 <总金币> <份数> [口令]`（或 `!fhb`、`!sendrp`） | 扣除金币并发出一个红包；不写口令时全服按编号抢 |
| `!抢 [口令或编号]`（或 `!qhb`、`!grab`） | 抢对应的红包；不填参数且场上只有 1 个无口令红包时直接抢它 |
| `!红包`（或 `!hb`、`!redpackets`） | 查看当前还没抢完、也没过期的红包清单 |

半角 `!` 和中文输入法的 `！` 都可以。如果口令里有空格，用英文双引号括起来，例如 `!发红包 100 5 "新年 快乐"`、`!抢 "新年 快乐"`。

## 管理员命令

只有写在「管理员」设置里的玩家可以使用。

| 命令 | 作用 |
| --- | --- |
| `!系统红包 <总金币> <份数> [口令]`（或 `!xthb`、`!sysrp`） | 不扣个人金币直接发一个系统红包并全服播报 |

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 管理员 `admins` | 空 | 可以在游戏里发系统红包的玩家名字，不区分大小写 |
| 最低总金额 `min_total` | `10` | 每次发红包最少需要的总金币，至少 `1` |
| 最大份数 `max_count` | `20` | 单个红包最多可分成的份数（`1` 到 `100`） |
| 过期时间（分钟）`expire_minutes` | `30` | 超过这个时间未领完时，剩余金额退回发包人（`1` 到 `1440`） |
| 最多同时存在红包数 `max_active_packets` | `10` | 场上未过期且未抢完的红包数量上限（`1` 到 `50`） |

修改配置后重载插件即可生效，已经发出的红包按发出时的过期时间结算。

## 说明

- 每个红包采用二倍均值法拆分，每人至少 1 金币，总金币至少要大于等于份数。
- 口令最长 24 个字符，不能是纯数字（纯数字留给红包编号）。
- 玩家发出的红包如果设置了口令，不能用 `!抢 <编号>` 绕过口令直接领取。
- 插件每分钟检查一次过期红包：个人红包未领完的剩余金币会自动退回发包人（发包人在线时立即私聊通知，离线时在下次进服时补发通知）；系统红包过期后不退回。
- 如果网络波动导致扣款或领奖结果暂时不确定，玩家会收到提示，可用经济插件的 `!流水` 查看实际入账情况。
