# 玩家档案

玩家每次进服时，记下他的名字、曾用名和账号的对应关系。其他插件（例如经济插件的转账）靠它按名字找到不在线的玩家。

本插件没有玩家命令，也不需要配置，装上即可。

## 记录内容

| 内容 | 说明 |
| --- | --- |
| 当前名字 | 玩家最近一次进服时的名字 |
| 曾用名 | 最近 5 个，按名字查找时同样能找到这位玩家 |
| 首次进服、最近进服 | 按 UTC 时间记录 |

- 按名字查找不区分大小写。
- 玩家改名后，旧名字还能找到他；曾用名超过 5 个时，最早的那个不再保留。
- 另一位玩家后来用了同一个名字，再按这个名字查找时找到的是后来的玩家。
- 每个玩家只有一份档案，数据量只随玩家人数增长。
- 只在玩家进服时记录。安装本插件之前就在线的玩家，下次进服时才会被记录。

## 给其他插件

服务 `plugin.neomega.players.resolve`（版本 1）：传 `name`、`uuid`、`xuid` 三者之一，返回 `id`、`name`、`uuid`、`xuid`、`names`（曾用名）和 `last_seen`。查不到时拒绝为 `not_found`，参数不是恰好一个时拒绝为 `invalid_argument`。`id` 是玩家的 uuid，没有 uuid 时为 `xuid-` 加 xuid。
