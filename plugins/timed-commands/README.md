# 定时命令

按固定间隔或每天的固定时刻，自动执行一组命令、向全服发送公告。装好后默认每个整点广播一句"感谢游玩，祝你玩得开心！"。不需要安装其他插件，也没有玩家命令。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 时区 `utc_offset_hours` | `8` | 每日时刻按这个时区计算，北京时间填 8 |
| 补执行宽限 `grace_minutes` | `5` | 到点后插件不在线超过这么多分钟，这一次就跳过，不再补执行 |
| 定时任务 `tasks` | 整点公告 | 最多 64 个任务，每个任务的写法见下表 |

每个任务：

| 字段 | 说明 |
| --- | --- |
| 任务名 `name` | 必填，不能重复 |
| 间隔分钟 `every_minutes` | 每隔多少分钟执行一次，例如 `60` 表示每个整点 |
| 每日时刻 `daily_at` | 每天在这个时刻执行，格式 `HH:MM`，例如 `20:00` |
| 执行命令 `commands` | 到点时依次执行的命令，开头的 `/` 可写可不写 |
| 全服广播 `message` | 到点时发给所有在线玩家的文字，留空则不广播 |

间隔分钟和每日时刻二选一：用间隔就把每日时刻留空，用每日时刻就把间隔填 0。执行命令和全服广播至少写一个。

示例：每天晚上 8 点清理掉落物并提醒全服。

```json
{
  "name": "晚间清理",
  "daily_at": "20:00",
  "commands": ["kill @e[type=item]"],
  "message": "已清理地上的掉落物。"
}
```

## 说明

- 间隔按整点对齐：`60` 在每个整点执行，`30` 在每小时的 0 分和 30 分执行。
- 新装插件或新增任务时不会马上执行，从下一个时刻开始。
- 同一个时刻只执行一次。插件重启后，如果到点还没超过宽限时间，会补上这一次；超过了就跳过，等下一个时刻。
- 某条命令执行失败不影响之后的执行。
- 命令由机器人执行，机器人需要有执行这些命令的权限。
- 修改配置后重载插件即可生效，只影响之后的执行。每个任务只保存一条记录，数据量不会随时间增长。
