# 个人传送点

玩家站在想记住的地方发送 `!设家`，之后随时发送 `!回家` 传送回来。每人可以设多个家，用名字区分。不需要安装其他插件。

## 玩家命令

| 命令 | 作用 |
| --- | --- |
| `!设家 [名字]`（或 `!sethome`） | 把当前位置记为家；已有同名的家时更新位置 |
| `!回家 [名字]`（或 `!home`、`!hj`） | 传送到这个家 |
| `!删家 <名字>`（或 `!delhome`） | 删除这个家 |
| `!家列表`（或 `!homes`） | 查看自己所有的家 |

名字省略时就叫"家"，最长 16 个字。名字里有空格时用英文引号括起来，例如 `!设家 "矿洞 入口"`。半角 `!` 和中文输入法的 `！` 都可以。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 每人最多几个家 `max_homes` | `3` | 到达上限后不能再设新名字的家，但可以更新已有的家 |
| 回家冷却（秒）`cooldown_seconds` | `10` | 两次回家之间至少间隔的秒数，填 0 不限制 |

调低上限后，玩家已有的家都保留，能照常回家，只是不能再新增。修改配置后重载插件即可生效。

## 说明

- 支持主世界、下界和末地。传送由机器人执行 `execute in … run tp`，机器人需要有执行这条命令的权限。
- 设家时需要读取玩家位置，偶尔读不到会提示玩家稍后再试，此时不会记录任何东西。
- 传送不检查目的地是否安全，玩家自己设的家自己负责。
- 冷却时间只在插件运行期间计算，插件重启后清零。
- 每个玩家只保存一条记录（他的所有家），数据量不会随时间增长。

## 版本说明

- 1.0.1：家记录脚的位置。1.0.0 把位置查询报的眼睛高度原样存下，回家会落在比设家时高 1.62 格的地方。升级后，1.0.0 设的家在回家时自动降低 1.62 格，玩家下次设家或删家时换算结果随记录保存；换算过的家带有标记，不会重复降低。服主无需操作，玩家也不必重设。
