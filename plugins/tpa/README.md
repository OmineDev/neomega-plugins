# 玩家互传

玩家可以请求传送到朋友身边，或者把朋友拉到自己身边，对方同意后立即传送。不需要安装其他插件。

## 玩家命令

| 命令 | 作用 |
| --- | --- |
| `!tpa <玩家>` | 请求传送到对方身边 |
| `!tpahere <玩家>` | 请求把对方拉到自己身边 |
| `!同意 [玩家]`（或 `!tpaccept`、`!ty`） | 同意请求；不写名字时同意最近收到的一条 |
| `!拒绝 [玩家]`（或 `!tpdeny`、`!jj`） | 拒绝请求；不写名字时拒绝最近收到的一条 |

半角 `!` 和中文输入法的 `！` 都可以。名字可以只写开头几个字母，不区分大小写；有多位玩家对得上时会列出他们的名字，请写得更完整一些。名字里有空格时用英文引号括起来，例如 `!tpa "Big Steve"`。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 请求有效时间 `request_timeout_seconds` | `60` | 超过这个秒数没有同意，请求自动失效 |
| 发起冷却 `cooldown_seconds` | `10` | 同一玩家两次发起请求之间至少间隔的秒数，填 0 不限制 |

修改配置后重载插件即可生效。

## 说明

- 传送命令由机器人执行，机器人需要有执行 `tp` 的权限。
- 同一个人对同一位玩家再次发起请求时，新请求替换旧请求。
- 发起请求的玩家下线后，这条请求就失效了。
- 请求只保存在内存里，插件重启或重载后，还没处理的请求会被清空。这个插件不保存任何数据。
