# 经济

服务器的通用货币。金币就是游戏里的一个计分板（默认 `coin`），其他插件（例如积分商店）通过本插件发奖和扣款；玩家自己可以查余额、互相转账、查看最近的收支。

安装时会一并装上「玩家档案」插件，转账时靠它找到不在线的玩家。

## 计分板就是余额

- 玩家有多少金币，以计分板上的分数为准。指令和命令方块可以直接读写这个计分板，例如 `/scoreboard players add @p coin 10`。
- 插件启动时，计分板不存在会自动新建一个，显示名就是货币名称；也可以按配置把它显示在侧边栏、玩家列表或名字下方。
- 从旧版升级时，旧余额不会搬到计分板上，最近收支照常保留。

## 不在线的玩家

计分板只能改在线玩家的分数，所以：

- 给不在线的玩家发奖或转账时，金币先记下来，等他下次进服时一次加到计分板上，并私聊告诉他"你离线期间收到 N 金币"。
- 扣款只对在线玩家进行；玩家不在线时扣款会被拒绝。

## 玩家命令

| 命令 | 作用 |
| --- | --- |
| `!余额`（或 `!ye`、`!balance`） | 查看自己有多少金币 |
| `!转账 <玩家> <数量>`（或 `!zz`、`!pay`） | 把金币转给其他玩家；对方不在线时，金币在他下次进服时到账 |
| `!流水`（或 `!ls`） | 查看最近 10 条收支，例如 `+10 签到奖励` |

半角 `!` 和中文输入法的 `！` 都可以。玩家名字里有空格时用引号括起来，例如 `!转账 "Steve Two" 10`。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 货币名称 `currency_name` | `金币` | 回复玩家时显示的货币名，也是新建计分板的显示名 |
| 计分板 `objective` | `coin` | 存放余额的计分板 ID，只能用英文字母、数字和 `_` `.` `-`，最长 16 个字符 |
| 自动创建计分板 `create_objective` | `true` | 启动时计分板不存在就新建一个 |
| 显示位置 `display_slot` | 空 | 留空不显示；`sidebar` 侧边栏，`list` 玩家列表，`belowname` 名字下方 |
| 初始余额 `starting_balance` | `0` | 玩家第一次进服时加到计分板上，每人只发一次 |
| 允许玩家转账 `allow_transfer` | `true` | 关闭后 `!转账` 回复"服务器已关闭转账"；其他插件的发奖和扣款不受影响 |

修改配置后重载插件即可生效。换了计分板 ID 后，余额从新的计分板读取，旧计分板上的分数不会搬过去。

## 说明

- 安装其他插件时，面板会列出它要使用的经济功能。只给信得过的插件批准"发放"和"扣款"，经济插件本身不另设名单。
- 扣款时先查余额再扣分。如果查完到扣分之间命令方块恰好也改了这个玩家的分数，扣款不会察觉，余额可能被扣成负数。
- 转账成功后双方都会收到私聊；收款方不在线时，付款方会收到提示，收款方进服时收到到账私聊。
- 每个玩家只保存最近 20 条收支和还没到账的金币，数据量不会随时间增长。更早的收支不再保留。
