# 经济

服务器的通用货币。每个玩家有一个整数余额，其他插件（例如积分商店）通过它发奖和扣款；玩家自己可以查余额、互相转账、查看最近的收支。

安装时会一并装上「玩家档案」插件，转账时靠它找到不在线的玩家。

## 玩家命令

| 命令 | 作用 |
| --- | --- |
| `!余额`（或 `!ye`、`!balance`） | 查看自己有多少金币 |
| `!转账 <玩家> <数量>`（或 `!zz`、`!pay`） | 把金币转给其他玩家，对方不在线也可以 |
| `!流水`（或 `!ls`） | 查看最近 10 条收支，例如 `+10 签到奖励` |

半角 `!` 和中文输入法的 `！` 都可以。玩家名字里有空格时用引号括起来，例如 `!转账 "Steve Two" 10`。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 货币名称 `currency_name` | `金币` | 回复玩家时显示的货币名 |
| 初始余额 `starting_balance` | `0` | 玩家账户第一次有收支时的金额 |
| 允许玩家转账 `allow_transfer` | `true` | 关闭后 `!转账` 回复"服务器已关闭转账"；其他插件的发奖和扣款不受影响 |

修改配置后重载插件即可生效。改初始余额只影响之后新开的账户，已有余额不变。

## 说明

- 安装其他插件时，面板会列出它要使用的经济功能。只给信得过的插件批准"发放"和"扣款"，经济插件本身不另设名单。
- 转账成功后双方都会收到私聊；收款方不在线时只记账，不补发消息。
- 每个玩家只保存余额和最近 20 条收支，数据量不会随时间增长。更早的收支不再保留。
