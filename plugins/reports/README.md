# 举报与留言

玩家在游戏里用 `!举报` 向服主和管理员举报违规玩家（自动附带举报人与在线被举报人的位置坐标），或用 `!留言` 提交建议和问题，并可随时用 `!我的举报` 查看处理进度与回复。管理员收到新提交或进服时会自动收到提醒，通过 `!查举报` 和 `!处理举报` 核实回复；如果提交人当时不在线，结果会在他下次进服时自动私聊送达。开箱即用，不需要安装其他插件。

## 玩家命令

| 命令 | 作用 |
| --- | --- |
| `!举报 <玩家名> <原因...>`（或 `!jb`、`!report`） | 举报玩家，原因支持多个词，最长 200 字；玩家名里带空格可用英文引号括起来 |
| `!留言 <内容...>`（或 `!ly`、`!feedback`） | 向管理员提交建议或留言，最长 200 字 |
| `!我的举报`（或 `!wdjb`、`!myreports`） | 查看自己最近 5 条举报或留言的状态与管理员回复 |

半角 `!` 和中文输入法的 `！` 都可以。

## 管理员命令

只有写在「管理员」设置里的玩家可以使用。

| 命令 | 作用 |
| --- | --- |
| `!查举报 [页码]`（或 `!cjb`、`!reports`） | 分页查看待处理的举报与留言（编号、类型、提交人、目标、原因、坐标、时间） |
| `!查全部举报 [页码]`（或 `!qbjb`、`!allreports`） | 分页查看全部记录，包含已处理结果与回复内容 |
| `!处理举报 <编号> <回复内容...>`（或 `!cljb`、`!resolve`） | 将指定编号标记为已处理并写明回复；提交人在线会立即收到私聊，不在线则下次进服时送达 |

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 管理员 `admins` | 空 | 填玩家名（不区分大小写）；这些玩家可使用管理员命令并接收提醒 |
| 提交冷却（秒）`cooldown_seconds` | `60` | 同一名玩家两次提交 `!举报` 或 `!留言` 之间至少间隔的秒数，填 `0` 不限制 |
| 最多保留记录数 `max_records` | `200` | 最多保存 20 到 1000 条；超出时优先淘汰最旧的已处理记录，仍超出则裁剪最旧记录 |
| 允许玩家留言 `allow_feedback` | 开启 | 关闭后 `!留言` 命令不可用 |
| 提交时提醒在线管理员 `notify_admins_on_submit` | 开启 | 玩家提交举报或留言时，立刻私聊通知当前在线的管理员 |
| 管理员进服时提醒待处理数 `notify_admins_on_join` | 开启 | 管理员进服且仍有未处理记录时，私聊提示待处理条数 |

修改配置后重载插件即可生效，已保存的举报与留言记录不受影响。

## 说明

- 提交 `!举报` 时会尝试采集当前在线玩家的位置坐标（显示为所在维度与脚下坐标），如果暂时采集不到，仍会正常保存举报记录，不附带坐标。
- 所有记录与时间均按北京时间记录和显示，提交冷却和离线通知在插件重启后依然有效。
- 提交记录达到上限时，会先清理最旧的已处理记录，尽量保留还未处理的记录。
- 管理员进服提醒会自动跳过插件刚启动时的积压历史事件，避免重复刷屏；玩家的离线处理通知在玩家进服确认送达后会自动清除，不会重复发送。
