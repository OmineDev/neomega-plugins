# 在线时长

每分钟给在线的玩家记 1 分钟，统计每天和累计的在线时长。当天在线满指定时间自动发奖励，还能查看累计在线排行。安装了经济插件时，当天在线每满一段时间还会发金币；没装也能正常使用。

## 玩家命令

| 命令 | 作用 |
| --- | --- |
| `!在线时长`（或 `!zxsc`、`!online`） | 查看今天和累计的在线时长 |
| `!在线排行`（或 `!zxph`） | 查看累计在线时长前 10 名 |

半角 `!` 和中文输入法的 `！` 都可以。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 时区 `utc_offset_hours` | `8` | 按这个时区的零点换日，换日后"今天在线"从 0 重新计，北京时间填 8 |
| 每日在线奖励 `rewards` | 在线 60 分钟送 5 个面包 | 每项写分钟数、命令和提示；当天在线时长正好达到该分钟数时发放，每天一次 |
| 金币间隔分钟数 `coin_interval_minutes` | `30` | 当天在线每满这么多分钟发一次金币，需要安装经济插件 |
| 每次金币 `coins_per_interval` | `5` | 每次发的金币；填 0 不发 |
| 每日金币上限 `daily_coin_limit` | `0` | 当天最多发这么多金币，最后一次按剩余额度发；填 0 不限 |

奖励命令里的 `{player}` 会换成获奖的玩家，提示文字会私聊发给他。金币和奖励命令互不影响，可以同时开启。修改配置后重载插件即可生效，已有的在线记录不受影响；把奖励分钟数改到某位玩家今天已经超过的值，这位玩家今天不会补发。

## 说明

- 机器人自己不计入在线时长。
- 插件每分钟统计一次，插件停止或机器人掉线期间不计时。
- 奖励命令由机器人执行，机器人需要有执行这些命令的权限。
- 金币结果暂时不确定时会提示玩家用 `!流水` 查看，这一次照样算进当天上限。
- 每个玩家只保存一条记录（名字、累计分钟、今天的日期、分钟和金币数），排行只保存前 10 名，数据量不会随时间增长。
