# 在线时长

每分钟给在线的玩家记 1 分钟，统计每天和累计的在线时长。当天在线满指定时间自动发奖励，还能查看累计在线排行。不需要安装其他插件。

## 玩家命令

| 命令 | 作用 |
| --- | --- |
| `!在线时长`（或 `!zxsc`、`!online`） | 查看今天和累计的在线时长 |
| `!在线排行`（或 `!zxph`） | 查看累计在线时长前 10 名 |

半角 `!` 和中文输入法的 `！` 都可以。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 时区 `utc_offset_hours` | `8` | 按这个时区的零点换日，换日后"今天在线"从 0 重新计，北京时间填 8 |
| 每日在线奖励 `rewards` | 在线 60 分钟送 5 个面包 | 每项写分钟数、命令和提示；当天在线时长正好达到该分钟数时发放，每天一次 |

奖励命令里的 `{player}` 会换成获奖的玩家，提示文字会私聊发给他。修改配置后重载插件即可生效，已有的在线记录不受影响；把奖励分钟数改到某位玩家今天已经超过的值，这位玩家今天不会补发。

## 说明

- 机器人自己不计入在线时长。
- 插件每分钟统计一次，插件停止或机器人掉线期间不计时。
- 奖励命令由机器人执行，机器人需要有执行这些命令的权限。
- 每个玩家只保存一条记录（名字、累计分钟、今天的日期和分钟），排行只保存前 10 名，数据量不会随时间增长。
