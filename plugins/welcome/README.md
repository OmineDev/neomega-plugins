# 欢迎与公告

玩家进服时私聊一句欢迎语；第一次来的玩家改发首次欢迎语，并领取一份新手礼包。另外按设定的间隔，轮流向全服广播公告。不需要安装其他插件。

## 玩家命令

| 命令 | 作用 |
| --- | --- |
| `!帮助`（或 `!help`、`!bz`） | 查看服务器帮助 |

半角 `!` 和中文输入法的 `！` 都可以。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 欢迎语 `welcome_text` | 欢迎回来，{name}！输入 !帮助 查看可用命令。 | 玩家进服时发送，`{name}` 换成玩家名 |
| 首次进服欢迎语 `first_join_text` | 欢迎 {name} 第一次来到服务器！送你一份新手礼包。 | 玩家第一次进服时改发这句；留空则发普通欢迎语 |
| 新手礼包命令 `first_join_commands` | `give {player} bread 16` | 玩家第一次进服时执行，`{player}` 换成该玩家；留空则不发礼包 |
| 帮助内容 `help_text` | 可用命令：!签到、!回家、!tpa 玩家名。有问题请联系管理员。 | 玩家发送 `!帮助` 时发送 |
| 公告 `announcements` | 请文明交流，祝你玩得开心！ | 按顺序轮流广播，播完最后一条再从第一条开始；留空则不发公告 |
| 公告间隔（分钟） `announcement_minutes` | `10` | 每隔多少分钟广播下一条 |

修改配置后重载插件即可生效，已经领过礼包的玩家不会再领。

## 说明

- 每个玩家只领一次新手礼包。机器人重连或服务器刷新玩家列表时，在线玩家可能会再收到一次欢迎语，但不会重复领礼包。
- 插件重启后公告从第一条重新开始轮播。
- 礼包命令由机器人执行，机器人需要有执行这些命令的权限。
- 每个玩家只保存一条"来过"的记录，数据量不会随时间增长。
