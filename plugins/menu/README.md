# 自定义菜单

服主在设置里配置菜单项，玩家发送 `!菜单`，在聊天栏里按编号选择，机器人执行对应的命令。菜单项也可以设快捷指令，例如 `!主城`，不打开菜单直接使用。每一项都可以设花费金币、冷却时间、仅管理员和分组。不需要安装其他插件；装了「经济」插件时，才能使用收费的菜单项。

## 玩家命令

| 命令 | 作用 |
| --- | --- |
| `!菜单`（或 `!cd`、`!menu`，可在设置里改） | 打开菜单 |
| `!菜单 分组名` | 直接打开某个分组 |
| 服主设置的快捷指令，例如 `!主城` | 直接使用这个菜单项 |
| `!指令`（或 `!zl`） | 列出本服可用的命令 |

半角 `!` 和中文输入法的 `！` 都可以。打开菜单后按提示回复：

1. 有分组时先输入分组编号，再输入菜单项编号；没有分组时直接输入菜单项编号。
2. 菜单项多时会分页，输入 `+` 看下一页、`-` 看上一页；编号在各页连续，看到哪个编号直接输入即可。
3. 收费的菜单项会先显示价格和余额，输入 `1` 确认后扣款并执行。

任何一步输入 `0` 或 `取消` 都会关闭菜单；30 秒不回复也会自动关闭；连续输错 3 次编号菜单也会关闭。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 菜单标题 `title` | 服务器菜单 | 菜单第一行显示的文字 |
| 打开菜单的指令 `menu_commands` | 菜单、cd、menu | 至少一个，不带 `!` |
| 每页条数 `page_size` | `8` | 3 到 20，超过就分页 |
| 管理员 `admins` | 空 | 玩家名列表，能看到和使用“仅管理员”的菜单项 |
| 菜单项 `items` | 回主城、领取面包、设为白天三个示例 | 见下表，至少一项 |
| 接管 !帮助 `help_takeover` | 关闭 | 打开后 `!帮助`、`!help`、`!bz` 也列出本服命令，见下文“帮助” |
| 帮助里列出的其他插件 `help_plugins` | 全部不勾选 | 勾选本服装了的官方插件，帮助里会列出它们的命令 |
| 帮助附加行 `help_extra` | 空 | 原样加在帮助最后，例如第三方插件的命令或联系方式 |

每个菜单项的写法：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| 显示名 `name` | 必填 | 菜单里显示的名字，不能和其他菜单项重复 |
| 执行的命令 `commands` | 必填 | 至少一条，按顺序执行；`{player}` 换成使用的玩家，例如 `tp {player} 0 100 0` |
| 快捷指令 `trigger` | 空 | 例如 `主城`，玩家发送 `!主城` 直接使用；留空则只能从菜单里选 |
| 以玩家身份执行 `as_player` | 关闭 | 见下文“命令怎么执行” |
| 花费金币 `cost` | `0` | 每次使用扣的金币，需要经济插件；0 为免费 |
| 冷却秒数 `cooldown_seconds` | `0` | 同一玩家两次使用这一项的最短间隔；0 不限制 |
| 仅管理员 `admin_only` | 关闭 | 打开后只有管理员名单里的玩家能看到和使用 |
| 分组 `group` | 空 | 填了分组的菜单项归到同名分组里；没填的直接列在分组后面 |
| 执行后提示 `message` | 空 | 执行后发给玩家的文字；留空则提示“已执行「显示名」” |

快捷指令和打开菜单的指令只能用文字、数字、`_` 和 `-`，开头的 `!` 写不写都行；它们彼此不能重复，也不能用 `指令`、`zl`，打开接管帮助时还不能用 `帮助`、`help`、`bz`。快捷指令不要和其他插件的命令重名（例如 `签到`），否则两个插件都会响应。

修改配置后重载插件即可生效；重载时正在打开的菜单会关闭，玩家重新打开即可。默认的示例菜单项坐标只是示意，请改成本服实际的位置。

## 命令怎么执行

- 所有命令都由机器人执行，机器人需要有执行这些命令的权限。框架不能让命令以玩家自己的权限执行。
- 默认按机器人执行：`{player}` 换成选中该玩家的选择器 `@a[name="玩家名"]`，例如 `give {player} diamond 1`。
- 打开“以玩家身份执行”后，每条命令前自动加上 `execute as @a[name="玩家名"] at @s run`：命令里的 `@s` 是这个玩家，`~ ~ ~` 是玩家所在的位置，例如 `tp @s ~ ~10 ~`、`effect @s speed 30 1`。权限仍然是机器人的。
- 命令开头的 `/` 会自动去掉。插件不检查命令是否执行成功，只负责把命令交给机器人。

## 金币与冷却

- 收费菜单项需要「经济」插件。没装或没启动经济插件时，玩家选收费项目会收到“暂时不能使用”的提示，免费项目照常使用。
- 金币不足时告诉玩家当前余额，不扣款也不执行。
- 网络不稳定、扣款结果不确定时，玩家会收到提示，可以用经济插件的 `!流水` 查看；没有扣款就重新使用，不会重复扣款。
- 少数情况下扣款成功但执行结果不确定，玩家会收到“请联系管理员”的提示，插件日志里记录了玩家、菜单项和扣款编号，可以对照 `!流水` 手动补偿。
- 冷却按玩家和菜单项分别计算，从执行时开始算，插件重启后仍然有效。每个玩家只保存一条冷却记录，过期的冷却在下次使用时清掉。

## 帮助

`!指令` 列出：打开菜单的命令、该玩家能用的快捷指令（普通玩家看不到仅管理员的项目）、服主在“帮助里列出的其他插件”里勾选的官方插件命令，以及“帮助附加行”。插件无法自动知道本服装了哪些其他插件，所以需要服主勾选；第三方插件的命令写在附加行里。

「欢迎与公告」插件也有 `!帮助`，内容是它设置里写好的一段文字。为了不重复回复，菜单插件默认不响应 `!帮助`，只响应 `!指令`。想让 `!帮助` 也显示自动生成的命令列表，可以打开“接管 !帮助”；但装了欢迎插件时它的 `!帮助` 仍会回复，玩家会收到两条，这时建议把欢迎语里的提示改成“输入 !指令 查看可用命令”，不打开接管。

## 说明

- 管理员按玩家名判断，名单写错或玩家改名后需要更新设置。
- 同一玩家同时只能打开一个菜单；菜单打开时玩家发的话会被当成菜单回复。
