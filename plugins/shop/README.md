# 积分商店

玩家发送 `!商店`，在聊天栏里按编号挑选商品，确认后用金币购买，商品由机器人发放。金币由「经济」插件管理，安装商店时会一并装上。

## 玩家命令

| 命令 | 作用 |
| --- | --- |
| `!商店`（或 `!sd`、`!shop`） | 打开商店 |

半角 `!` 和中文输入法的 `！` 都可以。打开后按提示回复：

1. 输入商品编号，例如 `1`。
2. 输入 `1` 确认购买。

任何一步输入 `0` 或 `取消` 都会关闭商店；30 秒不回复也会自动关闭。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 商店标题 `title` | 积分商店 | 菜单第一行显示的文字 |
| 商品 `items` | 面包 ×16（10 金币）、钻石（100 金币） | 每件商品写名称、价格和发货命令 |

每件商品的写法：

| 字段 | 说明 |
| --- | --- |
| 商品名称 `name` | 菜单里显示的名字，不能和其他商品重复 |
| 价格 `price` | 需要的金币，至少 1 |
| 发货命令 `commands` | 购买成功后执行的命令，`{player}` 换成购买的玩家，例如 `give {player} diamond 1` |

至少要有一件商品。修改配置后重载插件即可生效；重载时正在打开的商店菜单会关闭，玩家重新打开即可。

## 说明

- 发货命令由机器人执行，机器人需要有执行这些命令的权限。
- 打开商店时标题显示玩家当前余额。货币名和计分板跟随经济插件的配置，商店里不用另外设置。
- 金币不足时会告诉玩家当前余额，不会扣款。
- 网络不稳定、扣款结果不确定时，玩家会收到提示，可以用经济插件的 `!流水` 查看是否扣款；没有扣款就重新购买，不会重复扣款。
- 少数情况下扣款成功但发货结果不确定，玩家会收到"请联系管理员"的提示，插件日志里记录了玩家、商品和扣款编号，可以对照 `!流水` 手动补发。
- 商店本身不保存任何数据，余额和流水都在经济插件里。
