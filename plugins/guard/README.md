# 服务器守卫

替服主把好进服门槛、管住刷屏：等级不够、名字违规或服务器满员的玩家，进服后会先看到原因，几秒后被请出；刷屏的玩家先收到警告，再犯就踢出或按你设置的命令处罚。不需要安装其他插件。

装好后默认只开启防刷屏（先警告，再犯踢出）。三项进服门槛默认关闭，按需在设置里逐项打开。

## 能做什么

| 功能 | 默认 | 说明 |
| --- | --- | --- |
| 最低等级 | 关闭 | 玩家进服时检查经验等级，低于设定等级就请出 |
| 昵称黑名单 | 关闭 | 名字含有关键词（或匹配正则）就请出 |
| 人数上限 | 关闭 | 在线玩家超过上限时，请出最新进服的玩家；白名单里的玩家满员也能进 |
| 防刷屏 | 开启 | 10 秒内发超过 6 条，或同一句话发 3 次，就算刷屏；第一次警告，再犯踢出 |

不满足条件时，玩家会收到一条私聊和一个屏幕标题说明原因，等待几秒（默认 3 秒）后被踢出，踢出画面上也会显示原因。

## 谁不受检查

- 机器人自己永远不受检查。
- 设置里「管理员」名单中的玩家不受任何检查。
- 「人数上限白名单」中的玩家满员也能进，但仍算在在线人数里，其他检查照常进行。

## 管理员命令

| 命令 | 作用 |
| --- | --- |
| `!守卫记录 [条数]`（或 `!guard`） | 查看最近的处置记录，默认 5 条，最多 20 条 |

半角 `!` 和中文输入法的 `！` 都可以。只有「管理员」名单里的玩家能用。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 管理员 `admins` | 空 | 填玩家名，不区分大小写；这些玩家不受任何检查，并且可以查看处置记录 |
| 启用最低等级 `level_check` | 关闭 | 打开后检查进服玩家的经验等级 |
| 最低等级 `min_level` | `10` | 至少要达到多少级 |
| 启用昵称黑名单 `name_check` | 关闭 | 打开后检查进服玩家的名字 |
| 昵称关键词 `name_keywords` | 空 | 名字里含有任意一个词就请出，不区分大小写，例如 `广告`、`代练` |
| 昵称正则（高级） `name_patterns` | 空 | 用正则表达式匹配名字，不区分大小写；不会写可以留空，只用关键词 |
| 启用人数上限 `player_limit_check` | 关闭 | 打开后限制同时在线人数 |
| 人数上限 `max_players` | `20` | 最多允许多少名玩家同时在线，不含机器人 |
| 人数上限白名单 `player_limit_exempt` | 空 | 填玩家名或 UUID；这些玩家满员也能进 |
| 启用防刷屏 `spam_check` | 开启 | 打开后统计玩家发言 |
| 刷屏统计时间（秒） `spam_window_seconds` | `10` | 统计最近多少秒内的消息 |
| 最多消息条数 `spam_max_messages` | `6` | 统计时间内超过这么多条就算刷屏 |
| 重复消息上限 `spam_repeat_limit` | `3` | 统计时间内同一句话发到这么多次就算刷屏；填 0 不检查重复 |
| 警告次数 `spam_warnings` | `1` | 先警告几次，再犯才处罚；填 0 第一次就处罚 |
| 警告有效期（分钟） `spam_forgive_minutes` | `10` | 这么久没有再刷屏，警告次数清零 |
| 刷屏处罚命令 `spam_punish_commands` | 空 | 处罚时改为执行这些命令，`{player}` 换成该玩家，例如 `gamemode adventure {player}`；留空则踢出 |
| 踢出前等待（秒） `kick_delay_seconds` | `3` | 先显示原因，等几秒再踢出；填 0 立即踢出 |
| 等级不足提示 `level_message` | 需要达到 {level} 级才能进入本服务器，升级后再来吧。 | 也作为踢出原因，`{level}` 换成最低等级 |
| 昵称违规提示 `name_message` | 你的名字含有本服务器不允许的内容，请改名后再来。 | 也作为踢出原因 |
| 人数已满提示 `full_message` | 服务器人数已满（上限 {max} 人），请稍后再来。 | 也作为踢出原因，`{max}` 换成人数上限 |
| 刷屏警告 `spam_warning_message` | 请不要刷屏，再犯会被处罚。 | 警告时私聊发送 |
| 刷屏处罚提示 `spam_punish_message` | 你因刷屏被请出服务器。 | 处罚时私聊发送；踢出时也作为踢出原因 |
| 保留处置记录条数 `record_limit` | `100` | 只保留最近这么多条（10 到 500），旧的自动删除 |

修改配置后重载插件即可生效。

## 处置记录

每次警告、踢出或处罚都会保存一条记录：时间、玩家名、UUID、原因（等级不足、昵称违规、人数已满、刷屏）、处置方式和具体情况，例如「10 秒内发了 7 条消息」。只保留最近 `record_limit` 条，超出后最旧的自动删除，数据量不会一直增长。管理员在游戏里发送 `!守卫记录` 查看，时间按北京时间显示。

## 说明

- 框架只能在玩家进服之后处置，没法在进服前拦下；也不能撤回已经发出的聊天消息。
- 等级用服务器的 `testfor` 命令检查。服务器没有明确回复时（例如超时），这名玩家先放行，不会误踢。
- 人数满员时只请出超出的人数，从最新进服的玩家开始，管理员和白名单玩家不会被请出。插件重启后不知道谁先进服，这时按收到进服通知的先后判断。
- 机器人重连或服务器刷新玩家列表时，在线玩家会被重新检查一遍：已经在线、但名字或等级不符合的玩家也会被请出。
- 刷屏计数、警告次数只保存在内存里，插件重启或重载后清零。
- 刚安装或刚重启时，框架会先补发之前积压的聊天记录（新装的插件能收到最近一段时间的旧聊天）。这些旧消息只确认、不计入刷屏，等积压处理完（最多 60 秒）才开始统计；机器人重连前的聊天也不计入。
- 机器人暂时认不出自己的名字时，本次进服不做检查，避免把机器人自己踢掉。
- 踢出和处罚命令由机器人执行，机器人需要有执行 `kick`、`testfor`、`titleraw` 及处罚命令的权限。
