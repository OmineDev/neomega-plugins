# 每日签到

玩家每天发送一次 `!签到` 领取奖励。连续签到满指定天数，再发一份额外奖励。不需要安装其他插件；装了「经济」插件时，每次签到还会发金币，可以拿去「积分商店」买东西。

## 玩家命令

| 命令 | 作用 |
| --- | --- |
| `!签到`（或 `!qd`） | 领取今天的奖励 |
| `!签到信息`（或 `!qdxx`） | 查看连续签到和累计签到天数 |

半角 `!` 和中文输入法的 `！` 都可以。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 时区 `utc_offset_hours` | `8` | 按这个时区的零点换日，北京时间填 8 |
| 每日奖励命令 `commands` | `give {player} bread 3` | 每次签到执行的命令，`{player}` 换成签到的玩家；留空则只记录签到 |
| 签到成功提示 `message` | 签到成功，获得 3 个面包。 | 签到后发给玩家的文字 |
| 每日金币 `coins` | `10` | 每次签到发的金币，需要安装经济插件；填 0 不发 |
| 连续签到奖励 `milestones` | 连续 7 天送 1 颗钻石 | 每项写天数、命令、提示和额外金币；连续天数正好等于该天数时发放 |

连续签到中断一天就从 1 重新计数。修改配置后重载插件即可生效，已有的签到记录不受影响。

## 说明

- 奖励命令由机器人执行，机器人需要有执行这些命令的权限。
- 每个玩家只保存一条记录（最后签到日期、连续天数、累计天数），数据量不会随时间增长。
