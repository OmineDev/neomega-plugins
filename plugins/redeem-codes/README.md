# 兑换码

服主在设置里添加兑换码，玩家在聊天栏发送 `!兑换 兑换码` 领取奖励。每个码可以设奖励命令、金币、总次数、每人次数和过期日期。不需要安装其他插件；装了「经济」插件时，兑换码还能发金币。

## 玩家命令

| 命令 | 作用 |
| --- | --- |
| `!兑换 兑换码`（或 `!cdk 兑换码`） | 使用兑换码领取奖励，例如 `!兑换 XINSHOU2026` |

半角 `!` 和中文输入法的 `！` 都可以。兑换码不区分大小写，`xinshou2026` 和 `XINSHOU2026` 是同一个码。结果会私聊发给玩家：

| 情况 | 玩家看到的提示 |
| --- | --- |
| 成功 | 兑换成功提示（没填时显示“兑换成功！”），发了金币时附上金币和余额 |
| 码输错或不存在 | 兑换码不存在，请检查是否输错。 |
| 过了过期日期 | 这个兑换码已经过期了（有效期到 2026-12-31）。 |
| 总次数用完 | 这个兑换码已经被领完了。 |
| 自己已经用够次数 | 你已经领过这个兑换码了。（每人可用多次时提示“每人只能用 N 次，你已经用完了”） |
| 只发了 `!兑换` | 用法：!兑换 <兑换码>，例如 !兑换 ABC123 |

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 时区 `utc_offset_hours` | `8` | 判断过期日期用的时区，北京时间填 8 |
| 兑换码 `codes` | 空 | 每行一个兑换码，写法见下表 |

每个兑换码的写法：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| 兑换码 `code` | 必填 | 玩家要输入的码；只能用字母、数字、汉字、`-` 和 `_`，最长 32 个字，不区分大小写，不能和其他码重复 |
| 奖励命令 `commands` | 空 | 兑换成功后执行的命令，`{player}` 换成兑换的玩家，例如 `give {player} diamond 1` |
| 金币 `coins` | `0` | 需要安装经济插件，没装时不发，其他奖励照发；填 0 不发 |
| 总可用次数 `total_uses` | `0` | 所有玩家合计能兑换几次，填 0 不限 |
| 每人可用次数 `per_player_uses` | `1` | 同一个玩家能兑换几次，填 0 不限 |
| 过期日期 `expires` | 空 | 例如 `2026-12-31`，这一天过完后失效；留空不过期 |
| 兑换成功提示 `message` | 空 | 兑换成功后发给玩家的文字；留空显示“兑换成功！” |
| 备注 `note` | 空 | 只给自己看，玩家看不到，例如“开服活动” |

每个兑换码至少要有一条奖励命令或金币。修改配置后重载插件即可生效。

## 使用记录

- 每个码已经用了几次、每个玩家用了几次都保存在插件存储里，重启和重载不会丢。
- 记录按码保存（不区分大小写）。删掉一个码再加回来，原来的使用次数还在；想重新发放，请换一个新码。
- 调高总次数或每人次数后，已用的次数照旧计算，玩家可以继续兑换到新的上限。
- 多个玩家同时兑换同一个码，也会一个一个处理，不会超过总次数和每人次数。

## 权限

| 权限 | 用途 |
| --- | --- |
| 接收聊天消息 | 接收玩家的 `!兑换` 命令 |
| 执行命令 | 发放兑换码奖励并私聊回复玩家 |
| 读取在线玩家 | 确认发命令的玩家身份 |
| 经济插件发放金币 | 安装了经济插件时发放兑换码金币；没装时不使用 |

## 失败与异常

- 奖励命令由机器人执行，机器人需要有执行这些命令的权限。命令和使用记录一起提交，提交后由机器人执行，插件不等待命令的执行结果：命令写错或执行失败时，次数照样扣掉。新加的码请先自己兑换一次确认奖励正常。
- 每次兑换成功，插件日志都会记一行玩家、兑换码和提交编号，需要补发时可以对照查看。
- 网络不稳定、兑换结果暂时不确定时，玩家会收到“兑换结果暂时不确定……没有收到请联系管理员”的提示，插件日志记录玩家、兑换码和提交编号，插件随即自动重启：这次兑换要么已经生效（奖励照发、不会再发一次），要么没有生效（自动重新处理）。不会发两份奖励。
- 金币发放结果不确定时，玩家会看到“金币奖励结果暂时不确定，可以用 !流水 查看”；同一次兑换重复处理时，经济插件不会重复发金币。经济插件明确拒绝时提示“金币奖励暂时没有发出”，物品奖励和使用次数照常记录。
