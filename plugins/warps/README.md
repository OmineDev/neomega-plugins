# 传送点与主城

服主设置一些公共传送点和主城，玩家在聊天栏发命令就能过去；玩家还可以把重生点设在自己脚下。可以按次收取金币。不需要安装其他插件；想收传送费时再装经济插件。

## 玩家命令

| 命令 | 作用 |
| --- | --- |
| `!传送点`（或 `!warps`、`!csd`） | 查看所有公共传送点，带编号 |
| `!传送 <编号或名称>`（或 `!warp`、`!cs`） | 前往这个传送点；不写编号时同样列出传送点 |
| `!主城`（或 `!spawn`、`!zc`） | 传送到主城 |
| `!设重生点`（或 `!setspawnpoint`） | 把自己的重生点设在当前位置 |

名称不区分大小写。名称里有空格时用英文引号括起来，例如 `!传送 "矿洞 入口"`。半角 `!` 和中文输入法的 `！` 都可以。

## 管理员命令

只有写在「管理员」设置里的玩家可以使用。

| 命令 | 作用 |
| --- | --- |
| `!设传送点 <名称> [说明]`（或 `!setwarp`） | 把当前位置设为公共传送点；已有同名的会更新位置，不写说明时保留原来的说明 |
| `!删传送点 <编号或名称>`（或 `!delwarp`） | 删除在游戏里设的传送点 |
| `!设主城`（或 `!setcity`） | 把当前位置设为主城 |
| `!删主城`（或 `!delcity`） | 清除游戏里设的主城，改回使用插件设置里的坐标 |

插件设置里预设的传送点只能在设置里修改或删除，游戏里不能用同名覆盖。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 管理员 `admins` | 空 | 可以在游戏里设置、删除传送点和主城的玩家名字，不区分大小写 |
| 公共传送点 `warps` | 空 | 每条填名称、维度（0 主世界、1 下界、2 末地）、X/Y/Z 坐标和可选说明 |
| 传送冷却（秒）`teleport_cooldown_seconds` | `10` | 去传送点和回主城共用这个冷却，填 0 不限制 |
| 每次传送花费金币 `teleport_cost` | `0` | 需要安装经济插件；没装时不收费 |
| 启用设置里的主城 `city_enabled` | 关 | 开启后 `!主城` 传送到下面的主城坐标 |
| 主城维度与坐标 `city_dimension`、`city_x`、`city_y`、`city_z` | 主世界 0 64 0 | 管理员在游戏里用 `!设主城` 设的位置优先 |
| 允许玩家设重生点 `spawnpoint_enabled` | 开 | 关闭后 `!设重生点` 不可用 |
| 设重生点冷却（秒）`spawnpoint_cooldown_seconds` | `60` | 填 0 不限制 |

传送点名称最长 16 个字，不能是纯数字（数字留给编号），名称不能重复；说明最长 32 个字；最多 64 个传送点（设置里的和游戏里设的合计）。修改配置后重载插件即可生效。

## 收费

`teleport_cost` 大于 0 并且安装了经济插件时，每次成功传送前先扣金币：

- 金币不够时不传送，告诉玩家需要多少金币。
- 扣款结果暂时不确定时不传送，玩家可以用 `!流水` 查看是否扣了款。
- 冷却中或找不到传送点时不扣款。
- 没有安装经济插件时照常免费传送。

## 说明

- 支持主世界、下界和末地，可以跨维度传送。传送由机器人执行 `execute in … run tp`，设重生点执行 `execute in … run spawnpoint`，机器人需要有执行这些命令的权限。
- 设传送点、设主城和设重生点时需要读取玩家位置，偶尔读不到会提示稍后再试，此时不会记录任何东西。
- 重生点按玩家脚下所在的方块设置。
- 传送不检查目的地是否安全，请把传送点设在安全的位置。
- 冷却记录在插件数据里，插件重启后照样有效。每位用过传送或设重生点的玩家保存一条记录。
