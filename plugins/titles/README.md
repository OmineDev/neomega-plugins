# 称号与喇叭

玩家查看、购买、佩戴和卸下个性化称号，并用全服喇叭向全服玩家喊话。玩家佩戴称号后，会在进服播报和全服喇叭中展示头衔；普通聊天消息不会被截获或重发，不会出现公屏双条刷屏。不需要安装其他插件即可开箱使用；安装了「经济」插件时，可对称号购买和全服喇叭收费。

## 玩家命令

| 命令 | 作用 |
| --- | --- |
| `!称号`（或 `!ch`、`!titles`） | 私聊查看全部已配置称号（编号、名称、展示效果、价格/获取方式、拥有与佩戴状态）和可用指令 |
| `!买称号 <编号或名称>`（或 `!mch`） | 购买允许购买的称号；未佩戴称号时购买后自动佩戴 |
| `!佩戴称号 <编号或名称>`（或 `!pdch`） | 佩戴已拥有的称号 |
| `!卸下称号`（或 `!xxch`） | 卸下当前佩戴的称号 |
| `!喇叭 <内容>`（或 `!lb`、`!horn`） | 向全服玩家发送彩色喇叭广播（带当前佩戴的称号），支持多个空格词直接拼接 |

半角 `!` 和中文输入法的 `！` 都可以；编号即 `!称号` 列表中从 `1` 开始的序号，名称与称号 `id` 均不区分大小写，带空格的参数可用英文双引号括起来。

## 管理员命令

只有写在「管理员」设置里的玩家可以使用。

| 命令 | 作用 |
| --- | --- |
| `!发称号 <玩家名> <编号或名称>`（或 `!granttitle`） | 授予玩家指定称号；玩家在线时立即到账并通知，不在线时记入待生效队列并在其下次进服时自动合并通知 |
| `!收称号 <玩家名> <编号或名称>`（或 `!revoketitle`） | 收回玩家指定称号；若对方正在佩戴该称号会同时卸下，不在线时同样在其下次进服时生效 |

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 管理员 `admins` | 空 | 可以使用 `!发称号`、`!收称号` 的玩家名字，不区分大小写 |
| 称号列表 `titles` | 预设「开拓者」和「赞助者」 | 每项包含编号 `id`、名称 `name`、展示效果 `display`、价格 `price`、是否允许购买 `purchasable`、说明 `description` |
| 启用全服喇叭 `horn_enabled` | 开启 | 关闭后 `!喇叭` 不可用 |
| 喇叭费用 `horn_cost` | `10` | 每次发送喇叭消耗的金币（需经济插件，未安装时跳过扣费）；填 `0` 免费 |
| 喇叭冷却（秒）`horn_cooldown_seconds` | `15` | 同一玩家两次发喇叭之间至少间隔的秒数；填 `0` 不限制 |
| 喇叭提示音 `horn_sound` | 开启 | 发送喇叭时向全体在线玩家播放 `random.orb` 提示音 |
| 进服头衔播报 `join_broadcast` | 开启 | 玩家进服时若佩戴有称号，向全服播报其佩戴头衔 |

修改配置后重载插件即可生效；玩家存档按称号 `id` 保存，调整 `display`、`name` 或 `description` 后已拥有该称号的玩家自动同步新样式。

## 说明与收费行为

- **不拦截普通聊天**：普通白字聊天消息不会被改写或重新发送，插件只在 `!称号`、进服播报与 `!喇叭` 中展示称号。
- **收费与经济插件**：
  - 购买价格大于 `0` 的称号时，若未安装或未启动经济插件，会提示服务器未开启经济系统而无法购买；免费称号（`price = 0` 且 `purchasable = true`）不依赖经济插件。
  - 发送收费喇叭时，若未安装经济插件则视作免费跳过扣费；余额不足或扣款结果暂时不确定时不会发出喇叭，也不会进入冷却，玩家可用 `!流水` 核对扣款状态。
- **内容过滤**：`!喇叭` 会自动去除内容中的 `§` 颜色/格式控制符及换行等控制字符，防止伪造颜色或系统播报。
- **防重启刷屏**：刚安装或重启插件时，短时间窗口内连续补发的历史进服事件不会触发进服头衔播报，同时仍会为当前在线玩家合并待生效的离线发收称号。
- **权限与数据**：全服广播与提示音由机器人执行 `tellraw` 与 `execute as @a at @s run playsound random.orb @s`，机器人需要有执行这些命令的权限。每位玩家一条记录，喇叭冷却时间持久化保存，重启后仍然有效。
