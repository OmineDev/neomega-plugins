# 死亡点返回

自动记录玩家死亡时的坐标和维度，玩家在聊天栏发送 `!返回` 即可传送回上次死亡地点，也可以发送 `!死亡点` 查看上次记录的位置和剩余有效期。支持主世界、下界和末地跨维度传送，并可配置有效期、单次限制、冷却时间和返回费用（需经济插件）。

## 玩家命令

| 命令 | 作用 |
| --- | --- |
| `!返回`（或 `!back`、`!fh`） | 传送回上次死亡地点 |
| `!死亡点`（或 `!deathpos`） | 查看上次死亡位置、维度与剩余有效期 |

半角 `!` 和中文输入法的 `！` 都可以。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 位置采样间隔（秒）`sample_interval_seconds` | `15` | 后台定时记录在线玩家有效坐标的间隔（1–60 秒），用于即时查询失败、秒重生或跌入虚空时回退 |
| 死亡记录有效期（秒）`expire_seconds` | `600` | 死亡后多少秒内可以返回；填 `0` 表示不过期 |
| 单次有效 `one_time` | 开 | 开启后每次死亡记录只能成功返回一次；关闭则在有效期内可多次返回 |
| 返回冷却（秒）`cooldown_seconds` | `30` | 两次使用 `!返回` 之间至少间隔的秒数；填 `0` 不限制 |
| 每次返回花费金币 `cost` | `0` | 需要安装经济插件；没装或填 `0` 时免费 |
| 死亡后私聊提醒 `notify_on_death` | 开 | 记下死亡位置后私聊提示玩家发送 `!返回` |
| 允许返回虚空（y < -64）`allow_void_return` | 关 | 关闭时不记录 `y < -64` 的虚空位置，也会拒绝传送到此类位置 |

修改配置后重载插件即可生效，已有的死亡记录和冷却不受影响。

## 收费

`cost` 大于 0 并且安装了经济插件时，在确认可以传送后先扣款再传送：

- 金币不够时不传送，也不消耗单次返回机会和触发冷却。
- 扣款结果暂时不确定时不传送，玩家可以用 `!流水` 查看是否扣了款。
- 没有记录、记录已过期、已使用、冷却中或虚空禁止返回时不扣款。
- 没有安装经济插件时照常免费返回。

## 说明

- 支持主世界、下界和末地，传送由机器人执行 `execute in … run tp`，机器人需要有执行命令的权限。
- 玩家死亡时优先读取当前即时坐标；若处于秒重生、查询失败或跌入虚空（`y < -64` 且未开启允许返回虚空），会尝试回退使用最近采样（30 秒或两倍采样间隔内）的有效存活位置。若均无有效位置，不会覆盖旧的死亡记录。
- 死亡记录与冷却时间保存在插件数据中，插件重启后依然有效。
